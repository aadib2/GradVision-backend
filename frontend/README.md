# GradVision Frontend

Frontend for the GradVision web application.

Built with:

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

## Getting Started

Navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
